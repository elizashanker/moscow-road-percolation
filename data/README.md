# Данные

`raw/` — исходные снимки границ и дорожных графов. `processed/` — подготовленные графы и сведения об их обработке.

Большие исходные данные по умолчанию исключены из Git. Путь в задаче указывает, где файл должен находиться в локальной копии проекта. Для совместной работы команда отдельно выбирает общее хранилище; его нельзя считать настроенным автоматически.

Для каждой выгрузки сохраните:

- район, источник и точный запрос;
- дату и время получения;
- идентификаторы объектов OSM;
- версию библиотек;
- имена файлов и контрольные суммы;
- сделанные преобразования;
- ссылку на согласованное командой хранилище, если оно используется.

Публичные схемы и карты должны иметь атрибуцию OpenStreetMap. Лицензия исходных данных не заменяется лицензией собственного кода.
