# Результаты

- `tables/` — таблицы измерений и сводных показателей.
- `figures/` — карты и графики.
- `presentation/` — слайды и заметки выступления.
- `final/` — только согласованные файлы для официальной сдачи.

Промежуточные CSV, PNG и HTML в первых двух папках по умолчанию не добавляются в Git. Небольшие финальные файлы добавляйте адресно после проверки. Большие наборы повторов сохраняйте в согласованном общем хранилище; в репозитории должна остаться инструкция получения.

## Имя файла

Используйте латиницу и явное содержание: `khamovniki_local_near_threshold.png`, `runs_basmanny_random.csv`. Избегайте имён `final2` и `new_final`.

## Что обязательно знать о результате

Для таблицы: какие параметры использованы, какой исходный граф, какие seeds, какой программой получена.

Для рисунка: откуда взяты данные, какой район и сценарий, что означают цвета и оси. Реестр рисунков статьи — `paper/figures.md`.

Файлы `demo_*` относятся к искусственной решётке. Их нельзя использовать как результат исследования Москвы.
