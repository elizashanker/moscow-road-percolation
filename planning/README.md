# План GitHub Projects

`tasks.json` содержит 30 подробных задач: шаги, ожидаемые файлы, зависимости, даты, вклад в статью и критерии проверки. `project.json` задаёт девять представлений и поля.

Сначала откройте `docs/how-to-work.md`. Пути в задачах начинаются от корня репозитория. Назначения исполнительниц ожидают GitHub-ников; исходные даты внутреннего плана можно согласованно переносить.

Научная статья пишется параллельно по T25–T30, полный черновик — 27 ноября. Расширения не должны задерживать основной результат и статью.

Роадмап использует поля Start date и Target date. Если полосы ещё не видны, в настройках Date fields нужно выбрать эти поля и сохранить представление.
