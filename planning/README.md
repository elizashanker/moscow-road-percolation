# План GitHub Projects

`tasks.json` содержит 24 подготовленные задачи, даты, зависимости и критерии приёмки. `project.json` задаёт семь представлений и поля проекта.

Зависимости переводятся в ссылки на GitHub Issues при публикации. Если Projects не поддерживает автоматическую блокировку зависимостями, порядок работы контролируем через текст задачи и статус. Персональные назначения пока пусты.

Roadmap использует поля Start date и Target date; при необходимости их нужно явно выбрать в настройках представления. Даты расширений — резерв для планирования, а не обязательство реализовать все ветки.
