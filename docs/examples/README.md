# Пример автоматической проверки

`checks.yml` — готовый пример GitHub Actions. Сейчас он хранится как шаблон документации; автоматический workflow не включён. При необходимости перенесите его в `.github/workflows/checks.yml` через интерфейс GitHub или после выдачи разрешения workflow для GitHub CLI. Локальные проверки описаны в основном README.
