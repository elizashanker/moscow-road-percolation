# Источники

1. Li D., Fu B., Wang Y., Lu G., Berezin Y., Stanley H. E., Havlin S. (2015). *Percolation transition in dynamical traffic network with evolving critical bottlenecks*. PNAS, 112(3), 669–672. DOI: [10.1073/pnas.1419185112](https://doi.org/10.1073/pnas.1419185112). [Полный текст](https://pmc.ncbi.nlm.nih.gov/articles/PMC4311803/).
   Используем как опору для анализа компонент дорожной сети. В статье связи фильтруются по скоростям; наши искусственные закрытия задают другой эксперимент.
2. Zeng G. et al. (2019). *Switch between critical percolation modes in city traffic dynamics*. PNAS, 116(1), 23–28. DOI: [10.1073/pnas.1801545116](https://doi.org/10.1073/pnas.1801545116). [Авторская копия](https://havlin.ph.biu.ac.il/wp-content/uploads/Publications/23.full.pdf).
   Источник о различиях режимов перколяции реального городского трафика. Не переносим критические показатели и выводы о часах пик на наши два статических графа без проверки.
3. [OSMnx: User Reference](https://osmnx.readthedocs.io/en/stable/user-reference.html). Построение графов, проекция, преобразование направленного графа и сохранение данных. Фиксировать установленную версию.
4. [NetworkX: connected_components](https://networkx.org/documentation/stable/reference/algorithms/generated/networkx.algorithms.components.connected_components.html). Связные компоненты неориентированного графа.
5. [OpenStreetMap: Copyright and License](https://www.openstreetmap.org/copyright). На картах нужна атрибуция; условия данных рассматриваются отдельно от лицензии собственного кода.

Литература проверена по опубликованным статьям и официальной документации. Google Scholar можно использовать для дальнейшего поиска; сама поисковая выдача не заменяет чтение первоисточника.
