# Перколяция дорожной сети районов Москвы

Сравниваем, как дорожные сети **Хамовников и Басманного района** теряют связность при перекрытиях. Проект команды из пяти участниц для курса «Научная студия: перколяция».

[Доска и роадмап](https://github.com/users/elizashanker/projects/1) · [Задачи](https://github.com/elizashanker/moscow-road-percolation/issues) · [Wiki](https://github.com/elizashanker/moscow-road-percolation/wiki)

## Исследовательский вопрос

При какой доле закрытых участков дорожная сеть распадается на крупные компоненты и как результат зависит от района и расположения перекрытий?

В первой версии используем два сценария:

1. **Случайный:** удаляем участки в случайном порядке по всему району.
2. **Локальный:** выбираем случайную точку и последовательно закрываем ближайшие к ней участки. Расширение области задаём расстоянием до середины ребра в метрической проекции.

Сравниваем одинаковые доли **удалённых рёбер**, а дополнительно учитываем долю удалённой длины дорог. Все исходные вершины сохраняем, включая изолированные.

## Что считаем

- `q = m_removed / m_initial` — доля закрытых участков.
- `S1(q) = |C1(q)| / N0` — доля исходных вершин в крупнейшей компоненте.
- `S2(q) = |C2(q)| / N0` — доля исходных вершин во второй компоненте.
- `q_star` — значение `q`, при котором **средняя по реализациям** величина `S2(q)` максимальна. При плато показываем диапазон, а не скрываем его за одним числом.

Это операционная оценка распада конечной сети. Она не определяет точный момент «остановки города» и не доказывает фазовый переход бесконечной системы.

## Договорённости первой версии

- Источник дорог: OpenStreetMap, загрузка через OSMnx; анализ: NetworkX.
- Рассматриваем автомобильные дороги, но временно игнорируем одностороннее движение.
- Граф неориентированный, с сохранением параллельных физических участков.
- Начальные несвязные компоненты фиксируем. Автоматически оставлять только крупнейшую компоненту нельзя.
- Маршруты ограничены выбранной территорией. Проверку объездов за границей района проводим отдельно.
- Хамовники и Басманный — стартовая пара. Другие районы добавляем после основной версии.
- Реальные эксперименты пока не выполнены; демонстрационный граф не является картой Москвы.

## Быстрый старт

Требуется Python 3.11 или новее.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m unittest discover -s tests -v
python scripts/demo.py
```

Демонстрация не обращается к сети: она показывает сценарии на небольшой решётке и сохраняет CSV в `reports/tables/`. Для получения дорожных данных:

```bash
python -m pip install -e '.[geo]'
python scripts/fetch_osm.py --config configs/experiment.toml
```

Загрузка OSM требует интернета. Перед запуском проверьте, что найдены правильные административные границы. Сохраняйте исходный снимок и сведения о дате выгрузки.

## Развитие

Сначала завершаем сравнение двух районов и двух сценариев. Затем возможны:

- другие районы;
- метро вместе с пешеходными подходами, для оценки доступности людей;
- учёт направлений движения и обходов через соседние территории;
- сценарии по реальным данным о скоростях;
- затопление при наличии модели рельефа и явного правила закрытия дорог.

Центральность дороги не называем реальной загруженностью, а простую круговую зону — моделью затопления.
